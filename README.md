# ACM Diproyec Demo

Demo de una página corporativa para **ACM Diproyec**, desarrollada únicamente con HTML, CSS y JavaScript.

## Contenido

- Presentación principal y llamadas a WhatsApp.
- Servicios de diseño, presupuesto, construcción y supervisión.
- Proceso de trabajo en seis etapas.
- Catálogo inicial de productos.
- Portafolio de proyectos.
- Información de la empresa y datos de contacto.
- Navegación adaptable para computadoras, tablets y celulares.
- Espacios reservados para incorporar fotografías y renders reales.

## Ejecutar localmente

No requiere instalación de dependencias. Abre `index.html` directamente en el navegador o ejecuta un servidor local:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.
